## End-to-End Flow Snapshot | تدفق عالي المستوى
1. **Authentication & Session Bootstrap** – `AuthController` issues Sanctum tokens after validating credentials via `LoginRequest`; the frontend stores the token using `setAuthToken` inside `frontend/src/lib/api.ts` to hydrate Axios interceptors. 【F:backend/app/Http/Controllers/Api/V1/AuthController.php†L1-L92】【F:frontend/src/lib/api.ts†L1-L88】
2. **Dashboard Overview** – React dashboard modules call `API_ENDPOINTS.dashboard.overview` / `...analytics` and consume cached payloads generated by `HomeController` + `AnalyticsController`, which aggregate Eloquent statistics and memoize them for 5 minutes. 【F:frontend/src/lib/endpoints.ts†L24-L41】【F:backend/app/Http/Controllers/Api/V1/HomeController.php†L1-L63】【F:backend/app/Http/Controllers/Api/V1/AnalyticsController.php†L1-L83】
3. **Field Activity Lifecycle** – `ActivityController` validates filters, loads relationships, and returns `ActivityResource` collections. The frontend timeline module calls `API_ENDPOINTS.campaigns.activities` to render paginated field reports. 【F:backend/app/Http/Controllers/Api/V1/ActivityController.php†L1-L74】【F:backend/app/Http/Resources/ActivityResource.php†L1-L36】【F:frontend/src/modules/activities/api.ts†L1-L10】
4. **Communications & Alerts** – `SmsController` (via `SmsService`) enforces configurable rate limits, sends Twilio requests, and logs outcomes; client modules under `modules/automation` surface send status feedback. 【F:backend/app/Services/SmsService.php†L1-L48】【F:frontend/src/modules/automation/AutomationDashboard.tsx†L1-L80】
5. **Configuration & Governance** – Settings access flows through `SettingService::get`, translating stored types while controllers expose CRUD endpoints; the admin UI (settings module) consumes `/api/v1/settings` to manage operational knobs. 【F:backend/app/Services/SettingService.php†L1-L22】【F:frontend/src/lib/endpoints.ts†L4-L11】

## Deep-Dive Highlights | ملاحظات تفصيلية
### Authentication
- `AuthController::login` wipes previous tokens before issuing a new one with configurable expiry, guarding against stale device sessions. 【F:backend/app/Http/Controllers/Api/V1/AuthController.php†L31-L70】
- Registration enforces policy checks and assigns roles through `spatie/laravel-permission`, keeping RBAC centralised. 【F:backend/app/Http/Controllers/Api/V1/AuthController.php†L71-L108】
- Frontend Axios client injects bearer tokens automatically via the `withAuthorizationHeader` helper and caches responses where requested. 【F:frontend/src/lib/api.ts†L32-L104】

### Dashboard & Analytics
- `HomeController@index` aggregates voter, team, and event counts plus monthly registration stats returned via `HomeDashboardResource`. 【F:backend/app/Http/Controllers/Api/V1/HomeController.php†L1-L63】
- `AnalyticsController` joins activities, volunteers, and areas to build region summaries, support trends, and distribution breakdowns, caching results with a 5-minute TTL. 【F:backend/app/Http/Controllers/Api/V1/AnalyticsController.php†L1-L83】
- The dashboard module fetches committee geojson and live activity heatmaps through dedicated API wrappers, ensuring consistent request patterns. 【F:frontend/src/modules/dashboard/api.ts†L1-L15】

### Field Activities
- `ActivityController@index` supports optional filters (`type`, `status`, `area_id`, `from`, `to`) using query scopes defined on the `Activity` model (`forType`, `forStatus`, `betweenDates`). 【F:backend/app/Http/Controllers/Api/V1/ActivityController.php†L17-L47】【F:backend/app/Models/Activity.php†L1-L74】
- `ActivityResource` normalizes relationships (area, committee, creator) and timestamps to ISO 8601 for frontend consumption. 【F:backend/app/Http/Resources/ActivityResource.php†L1-L36】
- Frontend timeline components rely on strongly-typed responses (`ActivityListItem`, `ActivitiesResponse`) guaranteeing pagination meta alignment. 【F:frontend/src/modules/activities/types.ts†L1-L23】

### Communications & Automation
- `SmsService::send` enforces per-minute rate limits via `SettingService`, performs Twilio Basic Auth POST requests, and logs success/failure states. 【F:backend/app/Services/SmsService.php†L1-L48】
- Automation UI surfaces rely on shared status polling and log streaming (placeholder) inside `AutomationDashboard.tsx`; ensure API endpoints expose message history for richer UX. 【F:frontend/src/modules/automation/AutomationDashboard.tsx†L1-L80】

### Configuration & External Integrations
- `SettingService` casts stored values (integer, boolean, string) preventing type confusion when toggling features from the admin UI. 【F:backend/app/Services/SettingService.php†L1-L22】
- `ExternalApiService` standardizes outbound calls (base URL, timeout, caching, error wrapping) for connectors like mapping or analytics exports. 【F:backend/app/Services/ExternalApiService.php†L1-L52】
