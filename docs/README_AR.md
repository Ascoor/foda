## 🎯 نظرة عامة

**Elections360** هو نظام متكامل لإدارة الحملات الانتخابية داخل جمهورية مصر العربية.
يهدف إلى توفير منصة موحدة تجمع بين إدارة الناخبين، المندوبين، اللجان، الأنشطة الميدانية، والتقارير الاستراتيجية في نظام واحد يعمل بالزمن الحقيقي.

النظام مصمم ليكون بمثابة **غرفة عمليات انتخابية رقمية** تعمل على:
- تنظيم العمل الميداني واللوجستي.
- متابعة الناخبين واللجان لحظة بلحظة.
- تحليل البيانات الميدانية والإحصائية.
- إدارة الاتصالات متعددة القنوات (SMS / WhatsApp).
- إصدار تقارير فورية واستراتيجية لإدارة القرار الانتخابي.

## ⚙️ المكونات التقنية للنظام

| المكون | التقنية | الوظيفة |
|--------|-----------|-----------|
| **الواجهة الخلفية (Backend)** | Laravel 11 | واجهة برمجة التطبيقات RESTful API وإدارة الصلاحيات والأمان |

| **المتطوعين والميدان (Mobile)** | React Native (لاحقًا) | واجهة خفيفة للمندوبين الميدانيين |

## 🧩 الوحدات الأساسية للنظام (Modules)

1. **لوحة القيادة المركزية (Dashboard)**
   - عرض فوري لأداء الحملة.
   - خريطة تفاعلية لنسب التغطية والمندوبين.
   - إحصائيات: المؤيدين، المتطوعين، نسبة التفاعل.

2. **إدارة الناخبين (Voter CRM)**
   - سجل شامل للناخبين.
   - مستويات التأييد (محايد - مؤيد - متردد - معارض).
   - متابعة التفاعل والاتصالات السابقة.

3. **إدارة اللجان (Committees)**
   - بيانات المراكز الانتخابية.
   - إدارة المندوبين داخل كل لجنة.
   - تقارير الحضور والأنشطة يوم التصويت.

4. **إدارة المندوبين والمتطوعين (Agents & Volunteers)**
   - تتبع موقع المندوبين على الخريطة.
   - إرسال تقارير وملاحظات ميدانية فورية.
   - مهام وجدولة المناوبات.

5. **الأنشطة والفعاليات (Campaign Activities)**
   - إنشاء فعاليات الحملة.
   - إدارة المهام التنفيذية.
   - تتبع نسبة إنجاز الأنشطة.

6. **التقارير والتحليلات (Analytics & Insights)**
   - تقارير ميدانية فورية.
   - تحليلات المقارنة بين المناطق.
   - لوحات رسومية توضح نقاط القوة والضعف.

7. **الامتثال وحماية البيانات (Compliance)**
   - إدارة الموافقات (PDPL).
   - سجل معالجة البيانات.
   - إشعارات الصمت الانتخابي وسقوف الإنفاق.

## 🔒 الأمان والامتثال المصري (Reg-by-Design)

### القوانين المطبقة:
- **قانون حماية البيانات الشخصية رقم 151 لسنة 2020 (PDPL).**
- **إرشادات الجهاز القومي لتنظيم الاتصالات (NTRA).**
- **ضوابط الهيئة الوطنية للانتخابات (NEA).**

### تطبيق الأمان:
- تشفير البيانات في النقل والتخزين (AES-256 + TLS 1.3).
- إدارة الصلاحيات وفق أدوار المستخدمين (RBAC).
- نظام سجلات تدقيق (Audit Logs).
- حماية من هجمات CSRF / XSS / SQL Injection.
- استضافة محلية داخل مصر أو منطقة عربية معتمدة.

## 🧭 خارطة الطريق (Roadmap)

**الهدف:** بناء قاعدة النظام الأساسية

**المهام:**
- إنشاء قاعدة بيانات MySQL للنظام.

- عرض الخريطة الرئيسية للجان والمندوبين.
- إضافة خاصية التقارير الميدانية المباشرة (Live Reports).
