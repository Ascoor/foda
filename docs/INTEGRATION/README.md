# Elections360 Integration Overview

يستعرض هذا الدليل حالة التكامل الشاملة بين مكونات منصة Elections360، ويحدد الأدوار المتبادلة بين طبقات Laravel وReact ومحرك دورة حياة البيانات. يهدف هذا المستند إلى توحيد طريقة التشغيل قبل الانتقال إلى مرحلة الإنتاج المتقدم.

## الطبقات الرئيسية

1. **Laravel Backend**
   - يوفر واجهات REST، إدارة البيانات، وأوامر Artisan.
   - يعتمد على Doctrine DBAL لتتبع المخطط وإدارة المزامنة.
2. **React Frontend**
   - يعتمد على TypeScript لضمان توازي الأنواع مع النماذج.
   - يستهلك واجهات API ويعرض مؤشرات الأداء والأنشطة الميدانية.
3. **Data Lifecycle Engine**
   - يشرف على تهيئة البيانات العربية، تتبع الأنشطة، وإدارة عمليات المزامنة.

## مؤشرات الجاهزية

- تكامل المخطط (Schema) مع الواجهة الأمامية بنسبة 100% بعد مزامنة الأنواع.
- زمن استجابة API مستهدف أقل من 500ms لأكثر النقاط استخدامًا.
- تحديث تقارير التدقيق والمزامنة يوميًا ضمن مجلد `storage/logs`.
- أوامر التحقق والتشغيل موثقة ضمن هذا المسار.

## كيفية الاستخدام

1. نفّذ أمر التحقق الشامل:
   ```bash
   php artisan integration:verify
   ```
2. اختبر الأداء:
   ```bash
   php artisan api:profile --top=10
   ```
3. وحّد السجلات:
   ```bash
   php artisan logs:unify
   ```
4. اختبر دورة حياة البيانات:
   ```bash
   php artisan lifecycle:test
   ```

سيتم تحديث التقارير في `storage/logs` بعد كل تنفيذ، ويمكن مشاركتها مع فرق التشغيل للمراجعة والتوثيق.
