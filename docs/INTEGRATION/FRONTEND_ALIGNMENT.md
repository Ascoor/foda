# توافق React Types مع نماذج Laravel

تضمن طبقة React المطورة بـ TypeScript توافقًا مباشرًا مع نماذج Laravel. يوضح هذا المستند كيفية إدارة التزامن بين الجانبين.

## الخطوات الأساسية

1. **تعريف النماذج في Laravel**
   - يتم تعريف العلاقات والحشوات `fillable` داخل `app/Models`.
   - أي تغيير في النماذج يجب أن ينعكس في ملفات الأنواع.

2. **ملفات الأنواع في React**
   - توجد ضمن `frontend/src/types` ويتم استيرادها عبر الوحدات المختلفة.
   - تعتمد على نفس أسماء الحقول الموجودة في نماذج Laravel.

3. **عملية المزامنة**
   - شغّل أمر `schema:sync` بعد أي تعديل في المخطط.
   - استخدم `integration:verify` لرصد الأنواع الناقصة (مثل `CampaignBudget`).
   - يتم تحديث التقرير في `integration_report.md` مع أي حالة عدم تطابق.

4. **الاختبارات اليدوية**
   - تحقق من الواجهات المتأثرة (القوائم، الجداول، المخططات) بعد التعديل.
   - استخدم نماذج بيانات عربية من المصانع لتأكيد تنسيق النصوص بشكل صحيح.

## أفضل الممارسات

- حافظ على أسماء الحقول متناسقة (snake_case في Laravel، camelCase في React مع التعيين المناسب).
- أضف تعليقات TypeDoc للحقول الحساسة مثل الميزانيات والحصص الانتخابية.
- عند إضافة نوع جديد، أنشئ ملف TypeScript مستقل وصدّره عبر `src/types/index.ts`.

> **تنبيه:** يشير تقرير التكامل الحالي إلى نقص نوع `CampaignBudget.ts`. يجب إضافته أو توحيد الحقول في الواجهة الأمامية لتفادي تحذيرات المزامنة.
