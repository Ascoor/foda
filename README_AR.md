# FODA - نظام إدارة الانتخابات
## شرح متكامل للمكونات والواجهات

---

## 📋 نظرة عامة على التطبيق

**FODA** هو نظام شامل لإدارة الانتخابات مبني بتقنيات حديثة:
- **الواجهة الأمامية**: React + TypeScript + Vite
- **الخادم الخلفي**: Laravel 8 + MySQL
- **التصميم**: Tailwind CSS + shadcn/ui
- **الخرائط**: Leaflet + React Leaflet
- **الترجمة**: دعم العربية والإنجليزية

---

## 🏗️ هيكل التطبيق

### 1. الهيكل العام
```
foda/
├── frontend/          # الواجهة الأمامية (React)
├── backend/           # الخادم الخلفي (Laravel)
└── start.sh          # سكريبت تشغيل التطبيق
```

### 2. هيكل الواجهة الأمامية
```
frontend/src/
├── components/        # المكونات القابلة لإعادة الاستخدام
├── contexts/          # إدارة الحالة العامة
├── modules/           # وحدات التطبيق الرئيسية
├── pages/             # صفحات التطبيق
├── lib/               # المكتبات المساعدة
└── i18n/             # ملفات الترجمة
```

## 🔧 إدارة الحالة (State Management)

### 1. السياقات العامة (Contexts)
```typescript
// سياق المصادقة
AuthContext: {
  token: string | null
  login: (email, password) => Promise<void>
  logout: () => void
}

// سياق اللغة
LanguageContext: {
  language: 'ar' | 'en'
  direction: 'rtl' | 'ltr'
  toggleLanguage: () => void
  setLanguage: (lang) => void
}

// سياق المظهر
ThemeContext: {
  theme: 'light' | 'dark'
  toggleTheme: () => void
  setTheme: (theme) => void
}
```

### 2. إدارة البيانات
- **TanStack Query**: لإدارة بيانات الخادم
- **useState**: للحالة المحلية للمكونات
- **useEffect**: لتأثيرات جانبية

## 🚀 كيفية التشغيل

### 1. متطلبات النظام
- Node.js 18+
- PHP 8.0+
- Composer
- MySQL/PostgreSQL

### 2. تشغيل التطبيق
```bash
# تشغيل كامل للتطبيق
./start.sh

# أو تشغيل منفصل
# الخادم الخلفي
cd backend
composer install
php artisan serve --port=8000

# الواجهة الأمامية
cd frontend
npm install
npm run dev -- --port=8080
```

### 3. الوصول للتطبيق
- **الواجهة الأمامية**: http://localhost:8080
- **الخادم الخلفي**: http://localhost:8000
- **API**: http://localhost:8000/api/v1
